🧭 CareerCompass AI ✦

A smart, interactive career guidance and recommendation web application built using HTML, CSS, and JavaScript.

CareerCompass AI helps students explore technical career paths based on their interests and self-assessed skills. It provides personalized career rankings, skill gap analysis, learning roadmaps, and project suggestions through a modern, responsive user interface.

⚙️ How It Works

1. Choose Your Interests — Select the technical areas you want to explore.
2. Rate Your Skills — Evaluate your current abilities from 1 to 10.
3. View Career Matches — See career rankings update based on your ratings.
4. Explore Your Results — Review your top 5 recommended career paths.
5. Identify Skill Gaps — Discover which skills you could improve.
6. Follow a Learning Path — Get suggested learning steps and project ideas.
7. Compare Career Options — Evaluate multiple paths side by side.

The current prototype uses a transparent, weighted scoring algorithm based on predefined career-role profiles and selected interests.

Note: Match percentages represent alignment with the application's role profiles. They are not predictions of career success.

⚠️ Disclaimer

CareerCompass AI is an educational prototype designed to help users explore potential career paths. Its recommendations are based on self-reported skill ratings and predefined role profiles. They should be treated as guidance for exploration, not definitive career advice.

The current version uses a JavaScript-based scoring system. A Flask backend and trained Random Forest model are potential future enhancements, not features currently integrated into the application.
